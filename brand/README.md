# brand/

These files are copies of the master files of the Squadron Ready Room family: the insignia of Mission Plan and of the Ready Room, the symbol and pictograms, the tab and home-screen icons, the README banner and the social preview image. Do not modify them here; `brand_block.py` reads them at build time and embeds them in the pages.

Squadron Ready Room insignia: original artwork of the project; lettering from Oswald (SIL Open Font License 1.1), converted to outlines.
