# data/

Tables used by the **Flight Configurator** to compose a loadout station by station. They are copies, byte for byte, of the tables of the Loadout Editor of `dcs-mission-tools` (commit `03834f3ce7858af3aac4e7e0ffbd2f76cceccb3e`), where `data/README.md` describes their shape and how to regenerate them (`aircraft_masses.json` and `aircraft_views.json` are copies from commit `41fe3f452ea7d2330b6bfc55e9882c0eeb903f29`; `loadout_rules.json` is a copy from commit `1cdf22afd320e86b69805350a702ce0c4386f88c`).

- `weapon_names.json`, `aircraft_pylons.json`, `aircraft_limits.json`: generated from [pydcs](https://github.com/pydcs/dcs) **1.0.0**, **LGPL-3.0-or-later** ([`COPYING.LESSER`](COPYING.LESSER)). The tables carry the same licence.
- `aircraft_masses.json`: the empty weight and the recommended maximum weight of every aircraft type of the Loadout Editor (167 types, the 75 flyable types among them), for the take-off weight estimate (empty weight + fuel + stores; gun and countermeasures not counted). Values read from the aircraft definitions of DCS World (`M_empty`, `M_max`) and checked against the mission editor, **no licence added** (they are values). Byte for byte the same file as in `dcs-mission-tools`.
- `loadout_rules.json`: per aircraft type, the rules between stations that the DCS mission editor applies (`x`: a weapon that does not go with another station's load; `r`: a weapon that needs another one), read from the aircraft definitions of DCS World, **no licence added** (they are facts read from the game; the definitions themselves are not part of this repository). Byte for byte the same file as in `dcs-mission-tools`, where `data/README.md` describes its shape and how to regenerate it. The Flight Configurator reads it with the rules block copied from the Loadout Editor.
- `aircraft_types.json`: the game's flyable aircraft types for **HQ** (a squadron's aircraft in the wing configuration), from pydcs 1.0.0 `dcs/helicopters.py` and `dcs/planes.py` (the classes with `flyable = True`, by id, the type name in a .miz), **LGPL-3.0-or-later**. `aircraft_types_block.py` embeds it in HQ and stops the build unless it holds 12 helicopters and 63 airplanes, without duplicates.
- `aircraft_names.json`: the name shown for each of the 75 flyable aircraft types of `aircraft_types.json` (the type designation, for example `F/A-18C` for `FA-18C_hornet`, `Mi-8MTV2` for `Mi-8MT`): one table for every list and label of the suite. The `.miz` name stays the value written everywhere (package, work file, mission, wing configuration, presets). `aircraft_types_block.py` embeds it and stops the build unless it holds exactly the 75 types, each under its own name.
- `aircraft_radios.json`: for each of the 75 flyable types, the radios the mission editor presets (by number) and the number of channels it writes for each, read from pydcs 1.0.0 (`panel_radio` of each class in `dcs/planes.py` and `dcs/helicopters.py`), **LGPL-3.0-or-later**, like the pylon table. A type without a `panel_radio` has no programmable radio in the editor: `{}` (13 types, those of Flaming Cliffs). Regenerate it with `python3 tools/gen_aircraft_radios.py <pydcs 1.0.0 folder> data/aircraft_types.json data/aircraft_radios.json` (pydcs is read as text, never imported).
- `aircraft_templates.json`: for each of the 75 flyable types, the template **HQ** uses to create a flight that a mission lacks (helicopter or not, default task, maximum fuel, chaff and flares, group frequency, length and width, default unit properties, default radio channels by radio), read from pydcs 1.0.0 (`dcs/planes.py`, `dcs/helicopters.py`, `dcs/task.py`), **LGPL-3.0-or-later**, like the pylon table. An attribute a class does not give is absent from its entry (never `null`). Regenerate it with `python3 tools/gen_aircraft_templates.py <pydcs 1.0.0 folder> data/aircraft_types.json data/aircraft_templates.json` (pydcs is read as text, never imported).
- `parkings.json`: the parking stands of 11 DCS theatres and the size of every aircraft type, for the **Flight Configurator** (departure base and stand of a flight). Generated by `python3 tools/gen_parkings.py <downloads/parkings folder of dcs-airfield-charts>` from the [DCS Airfield Charts](https://github.com/MirabelleBenou/dcs-airfield-charts) data, which come from [pydcs](https://github.com/pydcs/dcs) (**LGPL-3.0-or-later**, like the pylon table); the Charts commit is named in the file's `source` line.
- `aircraft_views.json` and `views/`: the front-view drawings of 45 aircraft types, by **Goldwolf** (DCS Reference Guide), used with permission. They are **not covered by the repository's AGPL licence**: do not reuse them without the author's permission (see [`views/LICENSE.md`](views/LICENSE.md)).

`build_flight_configurator.py` embeds the tables in the module between `/* NAME:BEGIN */` and `/* NAME:END */` markers, and stops the build if an embedded copy differs from its file.
